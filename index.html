02 日常使用 三步启动，三条出图通道

启动（三步）

  • 双击桌面「启动ComfyUI.bat」——后端自动最小化到任务栏（标题带 Backend 8188，关那个窗口=停止服务）
  • Comfy Desktop 自动打开 → 点「远程连接」→ 127.0.0.1:8188
  • 不想用壳就浏览器开 127.0.0.1:8188

规则：一次只开一个实例（10GB 显存经不起两个后端抢）；双击后如果报端口被占，说明已有一个在跑，直接开浏览器用。

工作流库（左侧「工作流」面板）

  • 「Krea2·固定人设·官方版」——主力。官方 Turbo 模板改造：样本 A 提示词已填、云端增强已关、Ins 风 LoRA 已挂 0.8、种子 42 固定
  • 双击大节点进子图看内部实现（8 步 / CFG 1 / euler / simple / 负向 ConditioningZeroOut），能看懂就别改
  • 分辨率在 ResolutionSelector 下拉改（竖幅选 2:3 类预设）
  • LoRA 对比：选中 LoRA 节点按 Ctrl+B 旁路；种子 fixed 不变，只改权重 0.5/0.8/1.0 各跑一张
  • 「Krea2·官方示例」留作参照；它右侧弹的 darkbrush 缺失警告无视（别点内置下载，那是 HF 直连）

03 提示词方法论 会玩和不会玩是 2 个世界

四段式分工（换题材只动后两段）

段作用换不换
【画面风格】镜头/光线/质感（50mm、f/2.8、体积光…）固定
【核心元素】人物长相 + 服装 + 配饰——这就是「固定人物模板」，跨图一致的锚固定
【具体内容】动作、视线、前景背景、场景光每次换
【构图方式】半身/全身、机位、留白每次换
  • 服装换装：新服装描述写进【核心元素】，替换原服装那部分
  • 表情不用找图：直接描述（可爱脸 / 害羞脸 / 清冷脸）
  • 全身服装上身展示类，改用分层式：主体→表情→服装姿势→背景光线→构图→质感 六层逐层写

样本 A · 机械姬（当前工作流内置，可整段照搬到任意题材）

四段式固定人物模板

【画面风格】全画幅写实摄影，50mm定焦，f/2.8，光圈优先，精准单点对焦锁定面部，科幻冷调柔光，极致锐利清晰，体积光，柔焦虚化，环境光遮蔽。【核心元素】固定人物模板：东亚女性鹅蛋脸白皙，银白色短发，蓝眼睛，红润嘴唇，精致妆容，机械姬；白色机械装甲，金属质感，镶嵌蓝宝石，颈部与手臂露出机械结构，白色薄纱披肩，银色华丽头冠镶蓝宝石齿轮，服装与配饰物理空间绑定不可分离；本段白色科幻空间柔和侧光。【具体内容】人物身体微侧，双手交叠胸前，低头看胸前蓝宝石，视线向下，表情沉静；前景虚化机械零件，中景白色空间，背景柔光光斑；顶侧柔光，环境光遮蔽，阴影过渡柔和，50mm透视自然，人物与空间关系真实。【构图方式】半身（medium shot），微俯正面偏侧，对角线构图，人物居中偏左，右侧留白。

作者经验：套固定模板可以让人物跨图保持一致，「迭代了几十版了」。

LoRA 与采样经验（当天实测沉淀）

  • LoRA 决定「仙不仙」——画人务必挂人像 LoRA（Ins 风 / 风情万种），风格滤镜（MJ）可串联，权重 0.8 起步调
  • 对比要公平——seed 从 randomize 改 fixed，只动一个变量各跑一张，差异才能归因
  • 人脸一致性两条路——先出图再换脸（更简单），或把模特练成专属 LoRA（意义不大）
  • turbo 系参数铁律——8 步、CFG 1、euler/simple；负向接 ConditioningZeroOut 而不是负向词；CFG 设 3 反而劣化
  • 墨玉 AIO 单文件线——Load Checkpoint 一个节点顶三件套，免折腾通用底模，「画幻想生物也行」；发糊/过饱和再试 CFG 2–3.5

  • 把效果好的「服装+姿势」描述存成 prompts.json

05 排障手册 每一条都是当天真实撞过的墙

  • 工作流打开一片空白节点——前端 v1.57.4 不认手写序列化 JSON（有端口无标题无参数）。解法：刷新；根治：一律以官方模板为底改 JSON，别手写。
  • 模型下拉里找不到新文件——便携版启动时扫描模型目录，后加的文件要重启后端才可见；先查 extra_model_paths.yaml 是否挂对了目录。
  • HuggingFace 直连超时——全部走 hf-mirror.com；gated 仓库（krea/Krea-2-Turbo）下不了就用 Comfy-Org/Krea-2。
  • Comfy Desktop「没有可安装的兼容构建」——builder API 在你的网络直连不通（desktop/repo/launch.comfy.org 全超时），开系统级代理重启即可装；装好后它独立成第二后端，仍别和便携版同开。
  • 队列面板出现「正在执行 N 小时」僵尸任务——点清理队列/红色 X 清掉即可，历史记录没增长就是没真跑。
  • 官方示例弹「需要设置 krea2_darkbrush」——无视。那个 LoRA 没下载也不影响（开关默认旁路）；内置下载按钮走 HF 直连会卡死。
  • 显存爆了（CUDA OOM）——10GB 卡：分辨率别超 1024×1536 档；启动参数加 --lowvram；32GB 内存会自动卸载兜底。
  • CLIP 类型选错全图崩——CLIPLoader 的「类型」必须 krea2（不是 lumina2）；VAE 必须 qwen_image_vae（不是 minimax 视频那个）；不需要 AuraFlow 采样节点。
